บันทึกข้อมูลไว้บนเซิร์ฟเวอร์ของร้าน หน้านี้ทดสอบแผนที่จริงได้เมื่อมี Key ที่ถูกต้อง แต่ยังไม่เปิดแผนที่ในหน้าลูกค้าโดยอัตโนมัติ และไม่เรียกไรเดอร์

ข้อมูลแผนที่

ภาษาไทย • ประเทศไทย • Browser Key จะปรากฏในเบราว์เซอร์เมื่อโหลดแผนที่ ต้องจำกัดเว็บไซต์และ API ใน Google Cloud ไม่ใช้ Server Key หรือ Service Account ในช่องนี้

การทดสอบโหลดแผนที่จริงนับเป็นการใช้งาน Google Maps ใช้ค่าที่กรอกอยู่โดยไม่บันทึกอัตโนมัติ

Remark: ขั้นตอนขอใช้ Google Maps

  1. สร้าง Google Cloud Project ของร้าน
  2. ตั้งค่า Billing ด้วยบัญชีของคุณ
  3. เปิด Maps JavaScript API สำหรับแสดงแผนที่
  4. เปิด Places API (New) เมื่อต้องการค้นหาที่อยู่ และ Geocoding API เมื่อต้องการแปลงที่อยู่กับพิกัด
  5. สร้าง Browser API Key จำกัด Application restrictions เป็น Websites และจำกัด API ที่จำเป็น
  6. อนุญาตเว็บไซต์ร้าน https://pairattori-00129.github.io/* หากเปลี่ยนโดเมนต้องเพิ่มเว็บไซต์ใหม่
  7. ตั้งโควตา API และ Budget alerts ใน Google Cloud ก่อนใช้งานจริง
  8. กรอกค่าในหน้านี้ บันทึก และทดสอบแผนที่

Budget alerts แจ้งเตือนค่าใช้จ่าย ไม่ได้หยุดการใช้บริการอัตโนมัติ การตั้งโควตาต้องทำใน Google Cloud ไม่ใช่ในหน้านี้
