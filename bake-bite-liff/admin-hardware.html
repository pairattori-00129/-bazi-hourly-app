เว็บยังไม่ส่งคำสั่งเปิดลิ้นชักโดยตรง หากเลือกใช้ไดรเวอร์ ให้ตั้ง Cashbox Action ใน Windows เอง และการตั้งค่านี้อาจเปิดลิ้นชักทุกงานพิมพ์ การเลือกไม่ใช้ในหน้านี้ไม่เปลี่ยนการตั้งค่า Windows

การบันทึกและนำไปใช้

บันทึกค่าที่ร้านและนำไปใช้กับ POS / ใบครัวในเบราว์เซอร์นี้ อุปกรณ์หรือเบราว์เซอร์อื่นต้องเข้าหน้านี้แล้วกด “ใช้ค่าที่บันทึกกับอุปกรณ์นี้” อีกครั้ง

ชื่อเครื่องพิมพ์เป็นข้อมูลอ้างอิง เว็บไม่สามารถเลือกเครื่องใน Windows ให้เองได้ ต้องเลือกเครื่องที่ตรงกันในหน้าต่างพิมพ์ โหมดปัจจุบันยังแสดงหน้าต่างพิมพ์ ไม่ใช่การพิมพ์แบบเงียบ
