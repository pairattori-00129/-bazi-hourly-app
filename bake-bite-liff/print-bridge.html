Bake & Bite Print Bridge 0.2

Admin เป็นจุดตั้งค่าหลัก รองรับหลายสถานีและหลายเครื่องพิมพ์บนคอม Windows POS หลักเครื่องเดียว

สิ่งที่เปลี่ยนจาก 0.1.1

  • ไม่ต้องเลือกเครื่องเคาน์เตอร์และสถานีในตัวโปรแกรมอีก ตั้งจากหน้า Admin แล้ว Bridge โหลดตามประมาณทุก 3 วินาที
  • เพิ่มหรือเปลี่ยนเครื่องครัวไทย เบเกอรี่ เครื่องดื่ม และสถานีอื่นได้โดยไม่แก้โค้ด
  • โหลดเฉพาะสถานีที่เปิดใช้งานและเปิดใช้เครื่องพิมพ์ ส่วนสถานีที่ใช้จออย่างเดียวจะไม่สั่งพิมพ์
  • ถ้าไม่พบชื่อเครื่องใน Windows จะพักงานและลองโหลดค่าใหม่ ไม่เปลี่ยนไปใช้เครื่อง Default
  • งานที่ส่งแล้วไม่พิมพ์ซ้ำอัตโนมัติ งานที่ยังไม่ส่งจะใช้ค่าปลายทางล่าสุด

ดาวน์โหลด / อัปเดต

ผู้ใช้ 0.1.1 ให้ออกจาก Bridge ก่อน แล้วดาวน์โหลดไฟล์ .ps1 ใหม่แทนที่ไฟล์เดิมในโฟลเดอร์เดิม เก็บ state.json และ config.json ใน %LOCALAPPDATA%\BakeBitePrintBridge ไว้ เพื่อรักษาประวัติงานพิมพ์ โปรแกรมย้ายประวัติใบครัวเดิมให้เมื่อเริ่มครั้งแรก

1. Print Bridge 0.2 (.ps1)2. ตัวเปิดโปรแกรม (.cmd)

ตัวเปิด .cmd เดิมยังใช้ได้หากนโยบาย Windows อนุญาต หากก่อนหน้านี้คุณเปิดผ่าน PowerShell ให้ใช้วิธีเดิม รุ่นนี้ไม่เปลี่ยนนโยบาย Windows ให้เอง

ตั้งค่าที่ Admin ก่อนเริ่ม

  1. เปิด Display and Printer Settings และระบุชื่อเครื่องเคาน์เตอร์ เช่น XP-80C เลือกกระดาษและเปิดใช้เครื่องพิมพ์ แล้วกดบันทึกด้านล่าง
  2. แต่ละสถานี เช่น ครัวไทย ให้เปิดสถานีและ “ใช้เครื่องพิมพ์” กรอกชื่อ เช่น XP-C30 กำหนดหมวดสินค้า แล้วกด บันทึกสถานีนี้
  3. ถ้าเพิ่มเครื่องเบเกอรี่ ให้ติดตั้งไดรเวอร์ใน Windows ก่อน จากนั้นเพิ่มสถานีและกรอกชื่อคิว Windows ของเครื่องใหม่ ไม่ต้องแก้โปรแกรม Bridge
  4. ปิด “เปิดหน้าพิมพ์ใบเสร็จหลังยืนยันเงินสด” แล้วบันทึกและรีเฟรช POS เพื่อไม่ให้เว็บเปิดหน้าพิมพ์ซ้ำกับ Bridge
  5. เปิด Bridge แล้วเข้าสู่ระบบ POS จะเห็นรายการปลายทางจาก Admin และรายการเครื่องพิมพ์ที่ Windows พบ
  6. กด “ทดสอบทุกเครื่อง” โดยไม่สร้างยอดขาย เคาน์เตอร์ออกสองใบ และทุกสถานีที่เปิดพิมพ์ออกสถานีละหนึ่งใบ
  7. เมื่อตรวจครบ กด “เริ่มรับงาน” และเปิดโปรแกรมค้างไว้ บิล POS ใหม่ที่ชำระสำเร็จจะส่งใบเสร็จและใบรวมไปเคาน์เตอร์ ส่วนใบแต่ละแผนกจะไปเครื่องตาม Admin

เปลี่ยนค่าขณะเปิด Bridge

แก้ชื่อเครื่อง เปิด–ปิดการพิมพ์ หรือเพิ่มสถานีใน Admin แล้วกดบันทึก ไม่ต้องปิดหรือเปิด Bridge ใหม่ คอนโซลจะแสดง “โหลดค่าจาก Admin ใหม่แล้ว” เมื่อรับค่าใหม่ การกำหนดหมวดสินค้าใหม่ไม่ย้ายรายการออเดอร์เดิมที่เข้าคิวแล้ว

หากชื่อเครื่องว่างหรือไม่มีใน Windows จะขึ้น “พักงาน” และเก็บจุดทำงานไว้ แก้ชื่อใน Admin ให้ตรง แล้ว Bridge จะตรวจใหม่เอง

ขอบเขตและการตรวจสอบ

  • ยังเป็นรุ่นทดสอบ โค้ดพิมพ์หลักใช้แนวทางเดิมที่ทดสอบแล้ว แต่การโหลดค่าหลายสถานีรุ่น 0.2 ยังต้องลองกับ Windows และอุปกรณ์จริงของร้าน
  • เปิดบนคอม POS หลักเพียงเครื่องเดียว ไม่รองรับตัวเชื่อมหลายคอมพร้อมกัน
  • รับเฉพาะบิล POS ที่ชำระแล้ว ครั้งแรกไม่ย้อนพิมพ์บิลเก่า ครั้งถัดไปทำต่อจากประวัติที่เก็บไว้
  • ชื่อเครื่องเป็นชื่อคิวใน Windows ไม่ใช่ USB002 / USB003 ตัว Bridge ไม่เปลี่ยน Default Printer หรือไดรเวอร์
  • การส่งเข้า Windows ไม่ใช่การยืนยันว่ากระดาษออกจริง ถ้าค้างระหว่างส่งจะถามผู้ใช้ตรวจงานก่อนส่งซ้ำ
  • เมื่อสิทธิ์ POS หมดอายุต้องเปิดโปรแกรมและเข้าสู่ระบบใหม่ ไม่บันทึกรหัสผ่านหรือโทเคนลงไฟล์
  • ห้ามลบ state.json และ config.json เดิมตอนอัปเดต หากประวัติย้ายไม่ได้ ให้หยุดและแจ้งข้อความแทนการลบไฟล์
