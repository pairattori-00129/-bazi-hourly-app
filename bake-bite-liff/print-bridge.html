Bake & Bite Print Bridge

รุ่นทดสอบ 0.1 สำหรับ Windows 10/11 ใช้คอม POS หลักหนึ่งเครื่อง ส่งงานผ่านไดรเวอร์ที่ติดตั้งอยู่ ไม่ต้องตั้งเครื่องพิมพ์เป็น Default

เอกสารที่ส่งพิมพ์

เครื่องเอกสาร
XP-80C (เคาน์เตอร์)ใบเสร็จ และใบจัดอาหารรวมทุกแผนก
XP-C30 (ครัว)ใบงานเฉพาะสถานีที่เลือก

เลือกชื่อจริงจากรายการเครื่องพิมพ์ของ Windows โปรแกรมไม่เลือกด้วยหมายเลข USB โดยตรง

ดาวน์โหลด

ดาวน์โหลดทั้ง 2 ไฟล์ เก็บไว้ในโฟลเดอร์เดียวกัน เช่น โฟลเดอร์ BakeBite-PrintBridge บน Desktop

1. โปรแกรม Print Bridge (.ps1)2. ปุ่มเปิดโปรแกรม (.cmd)

ดูซอร์สและคู่มือบน GitHub ↗

ก่อนเปิดทดสอบ

  1. ตรวจว่า XP-80C และ XP-C30 พิมพ์ Test Page จาก Windows ได้ทั้งคู่
  2. ใน หน้าตั้งค่า ปิดตัวเลือก “เปิดหน้าพิมพ์ใบเสร็จหลังยืนยันเงินสด” แล้วกดบันทึก จากนั้นรีเฟรช POS เพื่อไม่ให้หน้าเว็บเปิดพิมพ์ใบเสร็จซ้ำกับ Bridge
  3. เปิดใช้งานสถานีครัวและ “ใช้เครื่องพิมพ์” แล้วกำหนดหมวดสินค้าให้สถานีนั้นและบันทึก
  4. ดับเบิลคลิก Start-PrintBridge.cmd แล้วเข้าสู่ระบบด้วยรหัส POS ของร้าน รหัสผ่านและโทเคนไม่ถูกบันทึกลงไฟล์
  5. เลือก XP-80C สำหรับเคาน์เตอร์ เลือก XP-C30 สำหรับครัว และเลือกสถานีที่ต้องการพิมพ์เข้าเครื่องครัว
  6. กด “ทดสอบ 3 ใบ” โปรแกรมจะส่งตัวอย่างสองใบเข้าเครื่องเคาน์เตอร์และหนึ่งใบเข้าเครื่องครัว โดยไม่สร้างยอดขาย
  7. เมื่อตรวจตัวอย่างแล้ว กด “บันทึกและเริ่ม” และเปิดหน้าต่างโปรแกรมค้างไว้ จากนั้นสร้างบิลใหม่ใน POS และยืนยันรับชำระ โปรแกรมจะส่งเอกสารให้ตามการตั้งค่า

หาก Windows แจ้งว่าไม่อนุญาตให้เรียกใช้สคริปต์ ให้หยุดและส่งข้อความแจ้งเตือนมาให้ตรวจ ไม่ต้องปิดระบบความปลอดภัยหรือแก้นโยบายทั้งเครื่อง

ขอบเขตรุ่นทดสอบ

  • รับเฉพาะออเดอร์จาก POS ที่ชำระแล้ว การเริ่มครั้งแรกไม่ย้อนพิมพ์บิลเก่า หลังจากนั้นจดจำจุดที่ทำค้างไว้
  • เครื่องครัวหนึ่งเครื่องผูกกับสถานีหนึ่งสถานี หากบิลไม่มีรายการของสถานีนั้น จะไม่ออกใบครัว
  • โปรแกรมส่งงานเข้าคิว Windows แต่ยังยืนยันไม่ได้ว่ากระดาษออกจริง ตรวจคิว Windows กระดาษ การตัดกระดาษ และภาษาไทยด้วยเครื่องจริง
  • หากงานค้างระหว่างส่ง โปรแกรมจะให้ผู้ใช้ตรวจว่าออกแล้วหรือยัง ก่อนเลือกข้ามหรือส่งซ้ำ
  • ติดตั้งและเปิดบนคอม POS หลักเพียงเครื่องเดียว ยังไม่รองรับหลายตัวเชื่อมทำงานพร้อมกัน
  • ต้องเปิดคอม มีอินเทอร์เน็ต และเปิดโปรแกรมอยู่ ยังไม่ติดตั้งเป็น Windows Service หรือเปิดพร้อม Windows อัตโนมัติ
  • สิทธิ์ POS มีอายุจำกัด เมื่อหมดอายุให้ปิดและเปิดโปรแกรมเพื่อเข้าสู่ระบบใหม่
  • เก็บชื่อเครื่องพิมพ์และประวัติงานใน %LOCALAPPDATA%\BakeBitePrintBridge ไม่ควรลบ state.json เพราะอาจทำให้การติดตามงานเปลี่ยนไป

ยังไม่ได้ทดสอบโปรแกรม Windows กับ XP-80C / XP-C30 จริง ต้องทดลองบนเครื่องร้านก่อนใช้งานประจำ
